## What it is

The RLHF stages end to end, built with TRL: supervised fine-tuning, human preference ranking, a reward model, and PPO. I also worked on an RLHF pipeline and QLoRA fine-tuning at Dolphant AI. The public repository, `train-test-regime`, holds the preference-data tooling.

## What is in the public repo

- A script to choose between model responses and one to rank them.
- A notebook that turns the rankings into a preference dataset.
- An experiments folder.

The repository's README is still empty, so treat the code as working notes rather than a polished library.
